# 《修仙系统模拟器》DeepSeek 叙事与文本量产任务书

> 用途：把所有零逻辑耦合的纯文本/JSON 叙事内容剥离出来交给 DeepSeek 批量生成，再由主工程校验（`Ajv` Schema + 世界观红线扫描）并直接并入 `src/content/` 驱动地图气泡、招徒名录、私令三视角、图鉴百科与战报演出。

## 一、不可逾越的世界观与词汇红线（验收刚性约束）

1. **游戏作品名**：《修仙系统模拟器》；**世界名**：修真界（严禁擅自改成「云岚宗 / 云岗宗」或现代网文穿帮梗）。
2. **十四境界枚举**：`凡人`、`淬体`、`炼气`、`筑基`、`紫府`、`金丹`、`元婴`、`出窍`、`化神`、`炼虚`、`合体`、`大乘`、`渡劫`、`无漏`（不得自造境界名称）。
3. **品阶枚举**：法器与功法分为 `凡阶`、`玄阶`、`地阶`、`天阶`、`帝器`；细分 `下品`、`中品`、`上品`、`极品`；灵根 `金木水火土雷风冰` 搭 `凡品 / 地品 / 天品`。
4. **灵石法则**：下品 / 中品 / 上品 / 极品换算率 `1:10,000`，**不存在合成炉把低阶灵石合成高阶灵石的设定**。
5. **三视角严密隔离（核心玩法铁律）**：
   - 玩家即绑定全宗的唯一「系统」，各宿主只知自身私令，旁人绝不可得知或暗示他人身怀系统；
   - 一切公开侧文案（`publicSummary` / `publicBubble` / `declineLine` / `auditionLine` / 战报丹报）**严禁出现**以下禁用词：
     `系统`、`【叮`、`私令`、`道源`、`道统根基`、`十轮修为灌注`、`宿主`、`任务面板`、`绑定`。

## 三、通用验收清单（导入前自检）

1. 全部产出为合法 **UTF-8 纯 JSON 数组或对象**，字段严格遵循约定的枚举键名；
2. 对所有公开文本字段执行禁用词检索，确保 `0` 命中 `['系统', '【叮', '私令', '道源', '道统根基', '十轮修为灌注', '宿主', '绑定']`；
3. 文本篇幅精炼耐看（气泡 8～16 字，出身/战报 25～65 字），贴合古典沉稳仙侠白描质感，少用现代网游数字轰炸词。
