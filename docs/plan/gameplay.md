# 修真界 · 招徒与放置养成玩法参考

开山收徒时，两个席位前可能站着三种值得押注的人。天品雷灵根的少年一夜就能参透引雷诀的第一幅图，宗门眼下却只有半部雷诀。凡品水火双灵根的应募者纳气慢，试炉时却能分辨两股药性何时相冲。还有个寿元渐紧的散修，带着一门完整符法，愿以授徒换一处安身之地。玩家收谁、用哪部传承养他、把难得的一次系统赐予留给谁，都会改变几十年后山门里擅长什么。下一次开山，还会来完全不同的人。

玩家在游戏外招徒、养成、经营和配置系统。游戏内的神秘系统已经接入宗主、长老和每一名弟子，新成员入门即绑定。每位宿主只能看见自己的提示、任务和奖励。言语、书信、演示或借第三人暗示都不能泄露系统存在。弟子可以公开约战或讨论炉火，旁人能看见行为，却不知道他收到了什么奖赏承诺。玩家能同时看到双方的私令，这个信息差是观战和布局的乐趣。游戏项目名待定，每一局由当次招进来的人担纲，可以一直开宗传代。

**招收弟子 → 放置修炼 → 规则触发修仙事件 → 人物与宗门收获成长 → 系统结算私令、开放新奖励 → 宗门有能力招到和养成另一批人。** 普通任务从开山之日便会自动发布。玩家最值得亲手做的事，是选人、定宗门方向、改一条能长期生效的奖赏规则，以及偶尔亲自给某个人开挂。

## 一、开山招徒，决定宗门下一代

**招徒前先选想遇见怎样的人。** 一次招募占用本期的一份招贤资源。地点、宗门名声、可提供的传承及上一代弟子的成就共同影响应募者。每名候选有独立的年龄和剩余寿元、境界与积累、灵根属性和品级、悟性、根骨、神魂、心性、可能显现的体质或血脉，以及愿意入门的理由。来历让这些差异有迹可循。铸坊出身者更可能熟悉炉具，灵根的属性与品级仍各自生成，炉火经验也可能落在一个纳气很慢的人身上。天赋决定可能走哪些路，眼下的功法、时间和物资决定能走多远。

| 怎么招 | 玩家能改变什么 | 这条路会带来什么后果 |
| --- | --- | --- |
| 在附属王朝开山门 | 广招能见到更多未经传授的苗子。带测灵器可辨灵根，请匠师同行则能多看一次试作 | 少年可塑性高，需占用师承和洞府多年。上届凡品弟子若已开创一门技艺，会吸引看重这门手艺的家庭 |
| 设问道会招散修 | 公布空缺的席位、可共享的功法和愿意兑现的条件 | 带艺入宗者能立即补上符、阵等空缺，也可能带着旧誓、伤势和未竟传承。承诺收徒却多年不给授业机会，会影响下次赴会的人 |
| 向盟宗与世家征求引荐 | 消耗人情指定所缺方向，如擅辨药性，或能驾驭冰属法器 | 来者资料较可信，也有独立意愿。宗门遵守借阅和授业约定，后来可能收到更珍贵的举荐 |
| 派游历弟子访贤 | 选择地域和寻访方向，让弟子挂机带回见闻与邀请 | 识兽者会注意到能安抚幼兽的凡人，剑修更容易认出隐居的同道。发现和入宗分开，对方还会衡量宗门是否适合自己 |

**识人也有选择。** 候选帖先给出已知资质、做过的事与一道未解的疑问。稀少的考察机会可拿去辨血脉，也可让某人试演本宗已有的功法。试炉成功能证明此人把握火候的能力，尚未觉醒的体质仍保留未知。同一批候选停留至本届招募结算，反复翻帖不会换人。离线可依“留一个特招席、优先补传承空缺”等规则接纳新人，值得关注的新苗归来时只报一次。

席位的价值取决于宗门能给新人什么。天品单灵根遇上合适传承，可以成为本宗首位跨过某个大境界的人。天品、稀有体质和好悟性各有来由，碰见其中一项已是喜事。声望能让难得的人才愿意赴约，凡品新人的实绩也会被下届招徒者看见。凡品多灵根在单一路线上较慢，却可能独自接通需要两属性轮换的阵眼。一个天资平常的老符师能把原来每次都要外购的遁符教给下一代。玩家可收藏关注对象，也可任其自行成长。已离山的候选可能投往别宗，在往后的论道会以新的实力再相见。

## 二、秘密任务与奖励，玩家怎样玩这个系统

玩家给系统的长期指示可以很简短。例如“优先培养尚无师承、但已显出一技之长的人。日常委托发本门讲法席，第一次独立完成前人做不到的事，准发一次特殊奖励”。系统自行寻找合格宿主、发私令、判断履约、兑付奖励。玩家也可以点名一人，给出一项只针对他的考验。

一条私令由**宿主、时机、可观察的目标、可用手段、期限、奖赏**组成。把目标定为“从强敌手中取得令旗”，弟子可以正面击败对方，也可以守住退路迫其弃旗。改成“在双方均未重伤时夺旗”，功法选择、出手时机和可能的赢家都会变。奖赏同样影响行为。求突破的人更想要静室和参悟机会，寿元紧迫者会为难得的养魂机缘冒险，重诺者即使面对厚赏也可能拒绝背弃师约。玩家能看到接受或拒绝的主要缘由，调整一次条件即可影响以后一类人。

**解锁合纵布令后，一次法会可以同时挂着三道互不知情的私令。**

| 收令者，由当前宗门选出 | 他独自看到的要求与奖赏 | 怎样算数 |
| --- | --- | --- |
| 已习两路剑式的参会弟子 | “取回试剑印，许你参阅藏经阁残页三日。” | 须在约定时限内实际持印离场。一路取胜、临场换式或从侧阵夺印都算 |
| 自愿与其较量的同辈 | “逼持印者在同一次交锋中改换剑路，授你一次观招留影。” | 须由自己的行动迫成变招。只看见对方预先换剑、只报一句获胜，均不算 |
| 当值长老 | “两人都能自行离台，开放一席阵道讲法。” | 只从公开可察的伤势与战况出手。太早封场会让前两人的目标落空，迟了也可能失约 |

夺印者赢了，对手仍可能因为逼出了第二式而领赏。若长老判断护身灵力耗尽而止斗，他自己的私令可能完成，另两人空手离台。若有人拒绝挑战，对手的私令在约定范围内另觅合资格对象，或到期取消。玩家既可故意制造竞争，也能设计秘密合作，例如让一人试出残阵的缺口、另一人趁阵眼熄灭时送入符种，两人都只需理解自己的事。宗门级任务对玩家显示总进度，对每一位宿主仍是私令。

假如此战真的既有变招又有夺印，两人的耳边会响起不同的提示。逼出变招的人听见“叮！对手受你牵制，由刺改挑。私令已成，观招留影已入识海。”持印者只听见“试剑印已带出。藏经阁参阅三日，自归山起算。”玩家则能同时看见这两次兑现，发现自己原以为互相冲突的两个目标，被他们用这种方式一并做成了。

**任务有代价，奖励有来处。** 实物奖励发约时预留库存，讲法和洞府占用真实名额，系统直接赋予的能力消耗道源。争同一件实物时明示胜者名额，合作的各方可各领事先承诺的不同报酬。拒绝、过期会释放尚未兑现的奖励。隐藏奖励可以给“以弱胜强且双方安全离台”这样的额外成就，条件在发令时即已确定。故意发高难考验能找到敢赌的人，也可能使重视稳妥的宿主以后更挑任务。弟子平常照样按自己的目标修行。

举例说，系统现有 120 道源，玩家要求留 40 备急，每份特殊参悟耗 20，本轮就能同时对四人许诺。若把规则从“最先破境的人得奖”改成“首次用低阶功法战胜克制者的人得奖”，同一笔预算会从将要破境的天才转向苦练偏门招式的弟子。无人满足时道源留存，日常委托照常流转。

### 系统本身也有养成线

**道源**是能花出去的力量。**道统根基**记录宗门通过系统影响首次达成的持久成就，用来开权限，消费道源不会降低已得根基。普通任务可积累少量道源，让自动奖赏有日常供给。更大的回款来自有分量的变化，如一位成员初入元婴、一门自创功法被第二人独立练成，或一类长期短缺由本门首次解决。同一成果拆发成十个任务只按一次成就计。日常按实际新增修行或产出计回馈，反复让高境者轻取同一弱者，很快只剩悬赏开支。全员绑定从入门起就生效，成长扩大的是系统能布置和兑现的事情。

| 权限成长 | 玩家新获得的玩法 |
| --- | --- |
| 初得系统 | 默认私令自动运转，可定向招徒、给单人加一项悬赏。开山获得一次有限的单人赐法，第一批普通弟子就值得挑选 |
| 领悟奖惩 | 自订“何人、何时、奖什么”的长期规则，设预算、优先级与自动保留额。此后收进来的新人同样适用 |
| 分授机缘 | 可奖一次借用神通、一次特殊参悟或一条能力变体。玩家能决定同样的道源养一群人，还是让一人率先跨过难关 |
| 合纵布令 | 编排并行、竞争、接力、保护等私令。可以一个人完成、两个人同领、有人失败却为另一人打开机会 |
| 开宗问道 | 将全宗目标拆成大量私人委托，依真实贡献解锁共用的新传承、招徒声望或探索权。擅长斗法、生产和研究的路线都能积根基 |
| 因果干预 | 在尚未落定的关键一刻改变一条具体条件，如让一位弟子在撤退前再保有一次施法机会。人物仍按当前状态行动，已经发放的奖励和已经发生的历史照常成立 |

权限页显示自己离下一项本领还差什么。例如，让三名不同宿主借同一类基础私令各自达成个人首次成就，便可将这类私令改成自订长效规则。若两道原本独立的私令恰在一场事件中相遇，两位宿主各自履约，系统就有了领悟合纵布令的契机。功法、工艺、对外贸易都可积累同等级的道统根基，玩家可以沿自己擅长的方向开宗门级权限。

### 主动给一个普通人开挂

点击弟子，选择赐予，玩家先看到这份力量能改哪条规则、能用多久、耗多少道源。取得权限和资源后，选谁、选哪项由玩家决定。授予后，新能力立即生效。拿到能力后遇到怎样的机会、能把它练到哪里，由弟子继续走。典型赐予可以这样设计。

- **留一息火。** 赐给多灵根弟子。原本从火息换成水息会中断控炉，现在换息时旧火能独立维持一息。一个凡品新人当场就有机会独自完成过去需要两个人配合的药方。用在斗法上，也能边持火障边引水卸力。火够不够、第二种术会不会，依然要靠养成。
- **借一式未来身。** 从本人正在修习且条件相容的功法中，借用一式尚未练成的神通。玩家可以把它给刚入门的普通剑修，让他在法会上劈开本来碰不到的护阵。施展一次即消散，法力不足会暂时透支，观招所得可以保留。选择教他扎根，或让他用这一剑替全宗拿到秘境入场资格，价值完全不同。
- **一败得师。** 指定一人吸收首次遭遇某类克制时的真实教训。若活着结束交锋，他能从确实承受过的一次招式中领出反制方向。主动约强者切磋就有新用途，故意反复败给同一招不会凭空长出新法。
- **逆命改根。** 攒足高阶权限、道源与极稀有的改命机缘后，玩家能点名改变一个人的灵根品级，为低资质的老弟子续开一条修行路。他已有的技艺、伤损与寿元仍然有意义。自然出现的逆天机缘极少，系统可主动使用已获的机会，普通修士后天升根仍极难。

玩家也可以把道源留给下次看中的新苗。宗门靠正常修炼、功法和实物生产能持续发展，定向赐予的吸引力在于它让一个原先无法成立的养法突然可行。

## 三、放置修炼，数字怎样改变人的道路

玩家给的是长效培养方向，例如稳固根基、尽快破境、主修剑法兼学符术，或留足寿元尝试自创新法。弟子自行安排吐纳、练法、闭关、求教、外出和恢复。达到一项上限就改练有收益的项目，偏重冒险的弟子也可能提前冲关。归来时能一眼看出瓶颈在哪里，以及再给一个洞府、一部口诀或一次系统赐予究竟会改变什么。

**一次闭关有三道实际限制。** 以某部心法的积气段为例，洞府每轮实供 9 缕，弟子能纳 8 缕，现有心法只来得及炼化 6 缕。六轮专修后，修为从 100 增到 136。换到每轮供 12 缕的洞府，他仍只多得 36。若改授能炼化 8 缕的相合心法，留在原洞府就能从 100 增到 148。若要抽两轮磨根基，余下四轮只增 32，却可能凑齐冲关前缺少的一重根基。玩家可以据此把好洞府留给真正缺灵气的人。

**积气圆满之后，破境还要逐关过。** 积累与根基决定能否启关，悟性和参悟所得决定能否找到行气路线，心性与既往心障决定扰动时能否稳住，剩余灵力和丹药决定能否撑过收束。只在尚有悬念的一关引入有限波动。根基不足者可以退回补修，强行冲关可能带伤，受惊扰者也可能只丢失这一次闭关的机会。普通破境丹可帮过一关，特殊丹药的可靠性要看其真实阶、品和适用前提。系统发“三日内筑基”时，三日可以是已积累数百年者的最后关口。若把同样私令发给初学者，普通办法无从完成。

- **灵根、体质与血脉。** 金木水火土及雷、风、冰等属性决定适配的灵气、材料和功法，凡品、地品、天品影响资质。根骨影响体修可承受的负荷，神魂影响分心御器、控阵和识破幻象的能力。特殊血脉可以有显化条件，如亲历雷场、神魂稳固且身上留有同源痕迹。强行催醒可能造成排异，暂缓能保住原有修行效率。
- **参悟、兼修与创法。** 功法由凡阶、玄阶、地阶、天阶至帝经。能得到一本高阶功法，与具备灵根、修为和领悟条件将它用好，是两次不同的收获。悟性帮助识别招式里的共同规律，经验提供可供比较的真实场合。水诀有“散势”，剑诀有“回锋”，在水势中确实数次成功卸劲的人，才有材料试出“顺水回锋”。功法决定平日怎样运气、能学哪些手段，神通则在满足条件时允许一个特殊行动，如隔着相连的水痕换位。两门功法若争用同一处运气时机便会中断或反噬，分心能力、改写顺序或系统赐法都可能解开冲突。自己偶然用成是一项感悟，能稳定重现才成为招式，写成谱、由相容的第二人独立学会，才成为宗门传承。
- **心境、丹毒与寿元。** 频繁吞服杂质高的丹药会积丹毒、耐药，短期快进可能让下一次收束更难。心魔从实际经历中的未了执念生发，重誓者因违约有心隙，争胜者可能追逐已失去的胜机。主动退关可保根基，带着同类经历磨出心法也可能化险为悟。老修士可转向授艺、冒险求突破或竞争难得的延寿资源，稀少延寿手段有真实代价。
- **境界质变。** 凡人 → 淬体 → 炼气 → 筑基 → 紫府 → 金丹 → 元婴 → 出窍 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 无漏。筑基可能历时二三百年。境界提升能开启原本没有的操作空间，例如炼气初能驱动凡阶法器，筑基具备发挥其全力的资格并可开始使用玄阶。高境者可以将更多精力放在阵法、授业和宗门大事上。渡劫时可让一道劫逐步耗去外阵、护身手段与心境余裕，事先学会的能力会逐项用上。各境寿元沿用设定中的暂定范围。

**同一个随机弟子也有几条真实养法。** 一名悟性好、根骨普通的火木双灵根，可以走烧尽护盾的剑修，学控火去炼丹，也可以专养只在特定火候下结籽的灵植。剑修抢到秘境首入权，丹修能替全宗降低丹毒，灵植师则能让下一代有稳定粮药。选哪条路会改变他占用的资源、容易遇到的师承、私令偏好和宗门以后来投的人。邪异功法也有吸引力，例如以承受一次真实反噬换来短时爆发。暴涨让他敢接越境挑战，未平复的心障又可能使其在退路将断时继续追击。能否自救取决于伤势、护持和已学手段。

## 四、动态文字事件，先发生，再演出

每件事都从世界里已经成立的条件出发。天候决定某处有无雷场，路线决定谁能到场，私令和性格决定到场后愿求什么。先判断可行行动，再比实际能力、资源和对手的应对，只对胶着或有不确定性的地方抽取一次波动。每一步消耗、负伤、迟疑、换招或发现都会改变下一步可选行动。修为、库存、知识、承诺、关系或环境确有变化才记一件修仙事件，平稳度过的时段并入修行进度。气运可以让拥有线索的人多遇一次恰当窗口，不能让从未进山的人带回山里的战利品。

境界、修为和熟练度决定实力大势。功法可开放一招反击，法器可承受一次重压，符箓能抢回一个行动时机，丹药会改变身体并留下丹毒，天气能接通原本断开的导雷路径。性格和经验主要改写出招、冒险、救援与退让的选择。界面显示综合战力用于估量强弱，展开可以看这一战真正用到了什么。

### 一场可以核账的争砂遭遇

雨后，两个炼气修士争一袋已采出的雷纹砂。持剑者综合战力 96，守砂者 112。后者把两份雷纹砂装进了囊中，上次遭遇留下的伤还在，现有气血 42/88。他正站在湿石上蓄雷，腰间有一张遁符。以下是这一组条件可能产生的一次记录，数值用于说明判定方法。

| 实际进展 | 当时为何如此，怎样改变下一步 |
| --- | --- |
| 战前准备 | 持剑者趁双方尚隔着石滩，先服随身的一份提气散。有效锋势从 30 升至 36，仅维持此击，丹毒从 2 到 5。若被贴身伏击，便没有这次服散的空隙 |
| 持剑者先动 | 他事先辨清了起手式，剑招准备从 6 拍减到 4 拍。对方蓄雷需 5 拍。若对方预先布好引雷符，只需 3 拍就能先出手 |
| 剑路命中 | 趁对方蓄势，持剑者可走已辨明的剑路，准度 53。此处短距明视，波动范围为 −2 至 +2，实际取 +1，得到 54，高于对方闪避 52，斩击落在灵盾上。若取 −2，只得 51，剑便落空，蓄雷有机会完成。若被水雾遮住出手方向，失准幅度还会扩大 |
| 护盾破，伤势加重 | 灵盾剩余容量 8，承下 8 后消散。护甲再消去 7 点斩击，实伤为 36 − 8 − 7 = 21。守砂者气血从 42 降至 21，进入不高于 22 的重伤区，蓄雷被打断 |
| 弃砂而遁 | 守砂者性情谨慎，胜算与现有伤势已低于他愿承担的危险。抛下重物让狭径可通，再耗掉遁符脱身。持剑者剩 11 点灵力，追击要 8，他的归途保留线是 6，遂收剑 |
| 双方带着结果离开 | 持剑者取得地上的两份砂，库存少一份散，多 3 点丹毒。守砂者失砂失符，保住性命，回宗养伤。下次炼器、配药和悬赏都从这个局面开始 |

**默认简报**可以只有三句。“剑光赶在雷声前落下，湿石上的灵盾应声而散。守砂人弃囊遁走，持剑者算了算归途的灵力，没有追。两份雷纹砂入库，一份提气散已用。”点开转折，会看到先手、实伤、退路与拒绝追击的依据。若当时护盾容量尚有 18，同一剑只造成 11 点伤害，守砂者余 31 点气血，仍有机会放出借湿石导通的雷术。实力更强者于是可能守住砂囊，同一地点能打出完全不同的一仗。

**切磋、伏击、追逐与救援各有结算目的。** 切磋可以夺旗或迫敌换式，先认输也可能完成秘密考验。伏击靠隐匿与对方警觉争取先手，踪迹早已暴露时会撞上反制。追逐看剩余灵力、负重、地形和是否保有退路。求援要有信号、有能抵达的援者，还要等得到他。普通战败多为败退、受伤或失物，只有严重失败或特定险局才可能身死。亡者的遗物、失传的半篇法门和留下的弟子继续影响宗门。常规复活须有完整魂魄、适配肉身、高深术法与巨大投入。

### 文字该让玩家看到什么

平常一行足够，如“符堂制得避尘符四张，朱砂余两份，下一批改用现存墨料”。重要事件把“出手前为什么敢赌、哪一次判定改变局势、谁付出代价”展开成几段，可随时略过。传奇事件给前史和意象更多篇幅，但每一个关键动词都要有依据。例如药师确实在将熄时留住一息火，炉中确实成丹，一名筑基同门也确实服此丹渡过最后一关，才写“旧炉里的最后一线火，终究没有灭。那一息火护下的丹，助同门叩开了紫府。”弟子对话只使用其能知道的事。玩家另可查看关联私令、具体运算、押下的实物与后续解锁。普通简报、详细演出、重复回看共用那一次胜负与结算。

## 五、修仙百艺，各有可以钻研的门道

丹、器、阵、符的技艺各有一至十品，需满足相应修为并实际学习和练习。丹药为一至十阶，每阶另分下、中、上、极品。材料阶、成品质量、作者技艺分开判断。下面几门本事各有自己的取舍，也能把产物交给另一条路线。

| 门道 | 人物在解决什么问题 | 成败留下什么，谁用得上 |
| --- | --- | --- |
| 炼丹、改方 | 依次提药、分火、合性、凝丹。药性强弱、杂质、炉温窗口与控火能力分别起效。替换辅药能拓宽窗口，也可能压低主药药力 | 同炉可得少量上品、多枚杂丹、偏性药液或废渣。首次变方需辨出药性才敢分发，稳定复现可入藏。疗伤、解毒、养魂和辅助破境各自解除不同困境 |
| 炼器、温养与修复 | 硬材能承力，通灵材能承术。淬成时检验材性是否相容、哪一条器纹真正接通。器修可牺牲一条受损器纹保住主体，也可试着重接 | 保住锋刃的剑可能暂失御水能力，改作破阵楔另有价值。损坏、掉品相对容易，升阶困难。凡、玄、地、天各分四品，帝器独立且常规不可锻造，真正器灵只可能在帝器中出现 |
| 制符、封术 | 符纸承载量、符墨属性、笔顺和封入术式决定能存几段效果。先隐去气息再移步与先移步再隐匿，在有守阵的地方会产生不同结果 | 遁符把撤离机会交给灵力不足者，护炉符可替丹师守一息温度。错笔可能缩短维持时长，也可能在错误时刻启动，鉴定和试用都值得投资 |
| 布阵、拆阵与借阵 | 阵眼的位置、通路、承载上限与供能决定灵力能到哪里。断掉一处会改道，供能不足时可保主阵、舍支阵 | 护山阵可以改连暖棚保下一季灵植，同时失去一处预警。探索者识得同一阵理，能让遗迹的封门暂时失去供能，争到另一条入内路线 |
| 灵植与选育 | 看种性、土中灵气、成熟窗、授粉来源。适时采药供眼前炼丹，留株结籽占田更久，也可能错过药性最盛之时 | 两片花期恰好重叠的灵田可能结出偏性种，再种一季才能看出能否稳定遗传。耐阴品种让闲置山坳变药田，古老天地宝药仍有其罕见生境 |
| 御兽与共修 | 妖兽辨人、进食、畏惧、蜕变各有习性。御兽者靠相处经验与神魂维持默契，可教会一项与其本能相配的动作 | 嗅矿兽在浓香药田里容易认错矿脉，却可能替灵植师找出病根。护主兽可能救人而错失猎物。脱契、负伤或换季迁徙会改变宗门的探索能力 |
| 鉴宝、论道与拓本 | 鉴宝者在器纹、磨损和来历中辨真伪。论道者用相异见闻解释同一段残诀，拿真实演法破除其中一个误解 | 低价旧鼎可能藏的是失传温炉法，价值在可传授的用法。过早定论会让宗门按错误属性备料。确证的拓本可换盟宗一次真传席，也可留给新一代自学 |

**同一炉丹有三种实际解法。** 某丹合药须药力至少 6，火候宜在 6～8。主药药力有 8，炉温起于 7。驱去两份杂质会把炉温抬到 9。符修预备的冷符能降 2，消耗一张，保住药力和成丹窗口。若只得寒性辅药，虽能降温，却会削去 3 点药力，只能收得可作他用的药液。若主炉者已掌握水火两息，又获赐“留一息火”，就能一面护住主药，一面切水息替辅药降温 2 点。这一炉省下一张冷符，火修照常可以用符走通同一丹方。成丹只改善服用者实际缺失的条件，服丹者仍须自行过关。

**材料也有选择去向。** 两份雷纹砂可补护山阵的一处导雷缺口，也可让合格器修尝试在玄阶法器上接通引雷纹。前者保住雨季灵田，后者给筑基弟子多一种战法。筑基驱动玄阶法器约能发挥一半，紫府才具备充分掌握的修为资格。宗门是先保住下一届弟子的资源，还是培养一个能去更危险遗迹的探索者，玩家只需更改长期投入方向。

## 六、出山以后，世界会做什么

秘境、遗物、妖兽、其他宗门各有自己的状态。弟子出发时只掌握本宗买到、见过或推断出的部分信息。玩家可以给一类探索定“先测绘、见强敌退”“优先抢首入”“只取活样”等原则。弟子带着原则和自己的脾气进去，途中可以发现原定目标已经不值得追。

| 活动 | 哪些条件让局势发生变化 | 可能收获，以及怎样影响下一次 |
| --- | --- | --- |
| 秘境勘探与夺宝 | 西漠一处遗迹白天石纹可辨，夜间星位合拢才开内门。先到者擅阵可校正石纹，擅体修可带回重石作拓，御兽者能探到狭缝。各法耗时不同，别宗同样会进场 | 取走一次性的宝物会留下空位，后人还能利用已经读懂的阵理。分享入口会失去独占时间，也可能换来对方保存的另一半图谱 |
| 追踪妖兽与迁徙 | 繁殖季、食物、地方天气决定兽群停留。追踪者能分清新旧足迹，但带着气味不合的契兽可能惊散整群 | 可以获材料、建立兽契、标出越冬地，亦可能空手。持续捕取会改变下季可遇种类，保住栖地则有机会引来愿意投师的御兽修士 |
| 特殊地势与环境规则 | 南疆毒雾封下层、冰洞逢暖渗水、雷雨使刻在湿岩上的纹路相通。弟子的解毒、辨气、御水或识阵能力决定哪些路实际可走 | 失去解毒手段后仍可在外围采样。精于制符者或能用提前封存的水术通过旱段。报告留下“哪种条件下走通过”，天气改变后旧记录仍有价值 |
| 现世遗谱与争道 | 散修、世家与宗门可能各有一段原文，目标有保密、求证、交易、争首传之分。能分辨伪章者有议价权，守信史影响谁肯出示原本 | 可独占半卷、合作拼出全卷、或因误修承受冲突。公示一个可靠的小发现可能招来同道，自家先得的传承也可能从此多一个对手 |
| 天象、天劫与心魔 | 观天者能提前缩小雷场出现的时间和方位，不能替应劫者承受。护阵抵消得越多，越早耗空储能。心魔抓住的具体破绽取决于人物曾经为哪些事失守 | 余力足者可能借一道真实经历完善护法术。外阵先毁也可能保住人却失去宗门设施。应劫者可以放弃额外淬炼求稳，预先选择冒险才会继续搏取更高收获 |

**一次夺宝可以全场无人交手。** 本宗探索者只持半幅星图，同行的外宗老修恰能辨伪章。前者从系统接到“最先带出阵眼拓本”的私令，后者想留住原物。若两人都精于鉴定，合作拓印能同时达成目标。若先到者判断错了星位，重启阵门会耗尽今夜的入内时机，后来者只能带回一次失败观测。若本宗私令改奖独占，双方实力接近且退路健全，同一处秘境也可能演成一场争夺。系统把局面交给真实进入的人。

## 七、宗门经营，养出不同的宗门

玩家控制招收规模、长期开支、设施用途与对外倾向。宗主和长老仍能自行调度宗务。普通邀斗、成批授课、采买和疗伤按政策处理，玩家只在想改变宗门走向时调整。扩张的关键问题总是“新招来的人能在这里学会什么，本门又会因他多会什么”。

**容量和供给是两笔账。** 假设一片洞府每轮能分出 24 缕灵气，三名弟子各需 8 缕。第四人加入后，均分只得 6 缕，也可让一人轮休参悟。多开一间静室解决安静闭关的席位，实供仍是 24。想提高实供，可付出真实灵石维持辅阵、取得额外修行地，或让部分弟子转练当期不争灵气的技艺。灵脉本身只能以极高代价有限改善。下、中、上、极品灵石都是天然实物，相邻默认 1∶10,000。交出去的低品灵石转到对方手里，兑回的高品灵石来自对方已有的天然储备。

| 长期经营选择 | 怎样形成优势 | 新的掣肘与招徒变化 |
| --- | --- | --- |
| 开丹堂、保灵田、资助试方 | 稳定的成丹法转成全宗疗伤与破境供给，剩余丹药可换缺少的器材 | 缺药性互补的种源时，再多丹炉也闲置。能够选育新种、辨杂质的申请人因此更有价值 |
| 立剑阁、办论剑会、奖新招 | 来客带来新克制，获胜者能开拓历练区域，落败者也可能留下能传授的反制心得 | 频繁论剑增加伤休和器修需求。天才被本宗剑谱吸引，原本不起眼的修器散修也可能成为最值得保留的名额 |
| 经营坊市与修复行当 | 鉴定和修复改变旧物的可用性。低价收来的一批破符器可换信誉，长期守约能换优先供货权 | 收一件帝器残片也要考虑能否鉴别、能否动用，稀物并不自动带来战力。价格、库存和别宗采购会回应宗门长期买卖 |
| 结盟守境，或争取新的资源地 | 联合防卫可换通行、互授或附属王朝的招徒权。接下有争议的矿权，则要在守阵、开采与谈判之间分配实力 | 战事按所争目标结算。可能守住山门却输掉一季矿额，也可能避免斗法换取共采。失信、毁约和伤亡会影响盟援、贸易与下一代来投的意愿 |

中州、东域、南疆、北荒、西漠是已知大陆的一部分。各地的传承、商业、妖兽与环境能改变来往者的构成。凡人王朝带来人口、凡间货物与招徒机会。别宗也会招走散修、在商会上竞价、为本门大修闭关而停办论道会。即使玩家整段时间专心炼丹，回山时也可能发现熟悉的坊市少了一位竞争买家，另一家宗门已经掌握昔日独有的符术。正道宗门有自己的执法堂，跨宗事务可以牵动地方与更高层级的正道盟。合欢宗及其正统阴阳双修属正道。魔功可能使实力迅速增长，使用者留下的伤害与恶行也会招来真实追查，魔教势力内部并不天然互信。外界能观察到本宗的做法，不能借一场纠纷得知宿主的秘密。

**传承是宗门最耐久的成长。** 一位丹师改良了一味辅药，个人成功一次只算心得。待药性、火候与替代条件弄清，第二人学会，才形成能交给后辈的丹方。若唯一掌握者在授艺前离世，后人只剩残稿，可通过旧炉痕、当年留下的药液或与别派交换资料重建。一位曾受本宗指点的外宗器修可能同意借炉鉴定。功法、工艺、情报和盟约就这样让下一批随机新人有不同的起点。

## 八、挂机以后，值得回来看的结果

宗门以同一套修行、探索、争夺和结算规则持续运转。弟子可拒单、换道、带伤休养，长老可以按既定底线止斗，错过的机缘也会落到世界里别的人手上。玩家预先设定对致命险境的态度。保守者默认退避，获准冒险者可以赌上重宝甚至性命。离线不会让人物突然改变风险偏好。普通事务自行收束，拒过的单和已发过的赏均按原结果留下。

**举一份归来时可能看到的摘要。** “本次发出的 108 道私令中，已完成 72 道，宿主拒接 20 道，到期 9 道，另有 7 道进行中。符堂已能独立供应遁符。新增一名元婴修士，系统获大额道源。你曾赐法的凡品弟子首次把双息控炉教给了别人。”这些条目只有真正发生才出现。普通进展按类合并，关注的人、改变养法的成果、首次突破或一次昂贵的失败优先呈现。玩家想看计算可以展开，想直接花新得的道源、改下一届招徒标准，也能马上做。

同一种投入可以沿着几条完全不同的路放大。

- **一笔赏，改变招徒池。** 奖励首位独立制成护炉符的人 → 丹师释放原用于守火的一次分心 → 可以同时维持两味相冲的药性 → 本宗首次可靠产出养魂丹 → 神魂受损的散修有理由来投。若符堂缺墨，丹师会用水息自解或改方，这批来客未必出现。
- **一个凡品弟子，改变百年后的强弱。** 玩家把一次借招赐给擅长识阵的人 → 他在论剑中拆开强者的护阵，虽然落败仍带回真实阵纹 → 阵堂有人能将它传下去 → 新弟子带着反制手段进入旧秘境。若玩家把同一次借招给天品剑修，剑修可能直接夺魁，换来的则是声望、更强的挑战者与招贤机会。
- **一次私令，既可催生天才也可能留下隐患。** 厚奖“首个带回未见功法的人” → 野心者抢下邪异残卷，短期实力暴涨 → 逞强追击使反噬提前 → 若已有养魂手段和可信的功法参照，可能逼出一条可传的变式。缺少条件则会带伤闭关，下一次大比的名额归了别人。玩家也能改发“验证其代价后方可领赏”，让下一批人愿意先研究再冒险。

长局中会有天才老去、普通人开宗立法、已遗失的符术被新秀补全，也有数代都等不来的机缘。任何一代都可以改招不同的人，换一种奖励，或选中一个本来走不到那里的人，亲眼看他迈出那一步。
