# 玩家为何要回山

玩家是秘密接入宗门的系统。宗主仍理事，弟子仍有自己的打算。玩家把有限奖赏押在一种做事方式上，观察谁响应、谁拒绝，以及这一次选择让谁在下一次机会中占了先。宗门靠委托、关系与传承成长。最小的长期奖励是“我认得这个人，也记得他为什么会这样做”。

## 一局药谷

从一个已有数年经历的小宗门开始。山门包括药房与演武场，另一处可去的地方是南疆药谷。六人的起始信息有意不对称，点击人物可看能力、在意的事和最近一段经历。姓名、地名细节及初态均为切片创作。

| 弟子 | 他会做出的不同选择 | 可以留下什么 |
| --- | --- | --- |
| 顾衡，炼气剑修 | 想胜过叶岑，敢于追击。受过援手后愿意护送对方的学徒 | 一次撤退可以使后来的人安全进谷 |
| 阿芷，凡品木灵根 | 熟识西径，重承诺。即使赏额低，也愿接应欠过人情的人 | 路标与徒弟都能留下。换成高战力剑修便失去这个机会 |
| 叶岑，炼气同辈 | 喜欢先探明敌性，愿接侦察，可能拒绝无退路的挑战 | 遭遇所得情报会改变下次切磋与出谷准备 |
| 闻舟，巡山弟子 | 重职责。守山时离开岗位有代价，对紧急救援会权衡例外 | 预警、接替和失约都可进入宗门史 |
| 许禾，已有基础丹道训练 | 优先保住伤员，材料不足时只处理现有药材 | 能把短缺转成教学机会。丹修品阶仍有修为与学习门槛 |
| 陆青，初学弟子 | 追随有实际传授意愿的人，愿用时间换学艺 | 学会辨路后可以替阿芷带队，让普通弟子也有不可替代的生涯 |

**第一次上线，约三分钟。** 雾将封谷，顾衡已经在东坡探路。阿芷熟悉西径，叶岑在山门等取样机会，两人只有一包药可带走。玩家可看他们的意愿与顾虑，设“接应优先”或“取样优先”，也可沿用原政策。首局的系统赏池有两份修行心得，开局只开放一份，第一次行动结案后的下一旬再开放第二份。药包独立记在实物账。发约冻结赏额，交付领赏，同一份拒绝、超时或撤回后可重派。全程无人接约时原有岗位仍运转。

| 相同起点 | 宗门可能怎样运转 | 下次上线值得考虑什么 |
| --- | --- | --- |
| 接应优先 | 药包留在山口。阿芷认出路标，顾衡遭遇妖兽时有退路，放弃追击。她给他包扎。药房少一包，采样窗口也可能关闭 | 顾衡欠下人情。把下一份委托用于阿芷传路，可让陆青独立带路。也可趁顾衡轻伤已稳再探 |
| 取样优先 | 药包随取样者出发。叶岑可能带回草标，许禾获得辨药线索。顾衡错过西径接应，自行从东坡撤出后休养更久 | 先让许禾教会学徒，还是暂缓研究补足疗伤药？两种投资各有受益者和机会成本 |
| 放手 | 日常由岗位和人物目标推动。默认先保命、守住已有承诺，机会可以过期。药房与师徒仍照常运行 | 回归纪事给出自动决定、依据及错过的机会。只需在觉得值得时改一次长效政策 |

这些是从规则可推出的示例。验收时要能换候选人、伤势或天气，得到另一个讲得通的结果。玩家可在出发前标记“我看好谁”，事后对照判断。这项观察不消耗货币，也不改变随机数。普通战斗随手略过，值得回看的是一场败退怎样成全了一个普通弟子。

## 弟子自己过日子

每人保留灵根属性和品级、已学本领、一个近期目标、两种可变性格倾向、当前事务、身体状态，以及少数真正影响选择的关系与记忆。每个活动都有地点、持续时长、资源占用和结束结果。只在活动结束、遇险、收到合适委托或处境明显改变时重新选择。

1. 先筛资格、占用、路径、伤势与承诺。重伤者能养伤、求援，不能凭高赏额出征。已答应照看伤员的人需要交班才可离开。
2. 对可行候选计算“岗位需要＋目标契合＋奖励吸引＋人情－风险－疲劳－毁约代价”。相近候选才用有种子的偏好扰动。解释保留最强的两个理由和一个被放弃的选项。固定最低承诺期，防止人物来回改主意。
3. 执行写回真实库存、空闲时间、伤势与见闻。轻伤可带伤换轻活。长期争强遇险后可能逐渐变谨慎。一次交流可以留下短期好感，一次舍弃机缘的搭救才足以形成持久人情。
4. 成长分三条线。修行积累影响境界，技艺需要练习和师承，经历开放新的行动。早期用学会一段路、一次控火或一个撤退时机呈现成长。大境突破要有足够的前史、根基与资源。普通破境丹只改善条件。

**上线节奏。** 开局到首次回看约 15～25 分钟，可放心关页。每次回归默认只给一条头条、最多两项余波和一个可选决定。下钻可看人物经历、事件父因、库存变动和未执行委托的原因。重复劳动合并成“许禾照料三批药草”，对关系、伤亡、传承、角色出入有影响的事留下姓名。搁置一个未决事项只占用相关人或物，其他人继续生活。

**更长的吸引力。** 前两小时看清同一批人的脾气。第二天让熟识的弟子第一次把知识交给别人，玩家能发现自己早先救过的人如今成了谁的师父。十至三十小时用人事更替、师承分支、资源紧缺和邻宗旧约改变现有事件的含义。老去、失手、错过开谷时机都有后路可经营。宗门拓展优先增加一种可传下去的经验或一种真正的取舍。用多日复访验证这些预期。

**宗门的收支。** 药材来自药田成熟或实地采集，处理、带队、授课和闭关都占同一人的时间。留一名熟手守药房能减少伤休，放他去教会第二人则缓解以后的岗位短缺。下一阶段把修行心得的来源接到首次掌握、传授和探索所得的新记录，各按事实 ID 一次入池。基础政策随时可用，储备稀少时仍有换岗、培养和守约可选。系统权限由长久的传承和成就开放，重复发同一差事不会扩大上限。

## 文本战斗怎样产生悬念

保留 V0.2 四段结算。第一步快照双方实力、当前目标、疲劳、灵力、携带物和地形。第二步挑选少量满足条件的转折（首版每战约 1～3 个），依次更新主动权、退路、伤势和耗用。第三步定胜负与代价，第四步从已提交事实投影 3～5 句简报及重点详报。显示压缩后的综合战力与“占优／相持／危险”和依据。玩家在培养、准备、留退路时作决定。

| 规则例 | 前提 → 作用 → 可观察的代价 |
| --- | --- |
| 借势反击 | 已学相应剑诀、敌方突进且尚有灵力 → 获得一次真正的反击机会 → 消耗灵力，仍可能只能脱身 |
| 护体与破防 | 护体诀蓄势可挡第一击。破防型敌人可提前击穿 → 产生护体耗尽事实 → 下一次同类攻击需要另谋退路 |
| 熟路撤离 | 当事人知道西径，或已收到实际路标 → 开放撤退选项 → 放弃追击和额外采获。谨慎者更愿意走，好胜者可能坚持 |

保留碾压胜、普通胜、惨胜、败退、惨败五类。切磋有明确切磋约束。严重失败或特殊险境才进入致死风险，先查预警、退出授权、护持、可达救援与时限。默认离线遇到新的不可逆风险先撤或保留一次有代价的救援机会。只有玩家事先明确接受该危险且条件成立，才可依政策结出生死。死亡留下人物志、直接原因、遗留关系与岗位空缺。救援机会逾期的行为随事先政策记录，不能靠等玩家点击拖住全宗。

首批两种敌性就用突进的谷狼和善守的岩甲兽。前者给剑诀借势的时机，后者会把好胜的人拖到雾封山道。低战力弟子读对脚印、提前留下路标，也可能比多练一次剑更能改变这一仗。

关键转折能改变“带回什么、谁受伤、欠谁人情”。这让快结算值得看。详报以同一 `battleId` 展开。跳过、更换视图、重载或关闭声音均不产生第二次收益。首版一对一，加场外接应。多人编队、法宝进阶和功法变体等单独验证后再加。

## 事件池怎样写，怎样验

采用有资格条件和状态后果的短事件。候选先经过地点、人物、修为、历史、世界状态和资源筛选。再按基础权重、性格契合、近期同类衰减和冷却加权。只有一个同类候选时也可以什么都不发生。使用“先绑定人物，再判关系”的做法，避免同一人既是伤员又是自己的救援者。重复文本可换措辞，影响数值或关系的句子必须能追到事实。[Storylets 设计方法，Emily Short](https://emshort.blog/2019/11/29/storylets-you-want-them/)

| 内容族 | 首批作者目标 | 初态或前因 → 本次落点 → 未来入口 |
| --- | ---: | --- |
| 日常、岗位 | 4 | 库房缺药 → 许禾请人接手药田 → 新学徒得到练习机会 |
| 修炼与瓶颈 | 3 | 弟子已有长期积累且休养充分 → 尝试调息或小步精进 → 下次对峙体力更充足 |
| 师徒与人情 | 3 | 曾受接应 → 愿护送对方的学徒 → 路线知识可传给第三人 |
| 竞争与纠纷 | 3 | 多次争同一名额 → 约定切磋 → 胜者留情或败者记怨，影响下次接应 |
| 探索与战斗 | 4 | 雾谷、足迹或草标 → 遭遇、撤退或采样 → 敌情或药性资料入库 |
| 势力互动 | M2 起 | 储药不足且邻宗曾相助 → 借药／延期履约 → 债务和信用改变下一封来函 |
| 系统例外 | M2 起，先做隔离夹具 | 候选人有相关前史、宗门级稀有窗口开启 → 一次特殊机缘 → 永久标注系统来源、见证者和代价 |

首版以约 17 个模板、至少三条可交叉的三步因果链为内容上限参考。优先做好“接应 → 人情 → 传路”“取样 → 辨药 → 授艺”“切磋 → 负伤 → 换岗”，支持拒绝、错过或被另一人接手。事件库扩量按出现过的重复、沉寂的角色和缺失的后果定向补写。极罕见例外只在全宗合格窗口抽一次，独立随机流和冷却持久化。人数、开页次数和反复读档不得增加抽取次数。测试可强制覆盖例外，首局须在零奇遇时也成立。精确自然发生率及破例边界留给后续样本与世界审定。

可先用下面的试算值校准 M2。普通窗口用“无事”权重 5、岗位变化 2、合格的人情后续 3，只归一化当时合格的项。关键因果如已送达的药包走必然效果，不再抽签。极罕见机缘先试每宗每世界年最多一次合格抽签，每次 1/512，没有合适人物就跳过。连续五个全合格窗口至少出现一次的概率约 0.97%。批跑时记录“合格窗口数／抽签数／触发数”，强制触发用例单独统计。此数只用于首轮试算。

**内容交付单位是一个能复玩的事件。** 作者交触发与不触发样例、一个替代人选、效果与后继、事实句式和一次失败路径。校验器查重复 ID、缺引用、年龄／修为／地点冲突、无出口循环、角色不互异、负库存与不可达分支。固定种子跑正反例，随机种子跑频率、重复间隔与人物覆盖。读者应能在隐藏数值时说出为什么是这个人。新增条件和独特功法可以扩展规则接口，附反例与兼容版本即可。成熟分支叙事工具可留给有固定对白的支线，状态真相始终来自模拟。[inkle 的 ink](https://github.com/inkle/ink)
